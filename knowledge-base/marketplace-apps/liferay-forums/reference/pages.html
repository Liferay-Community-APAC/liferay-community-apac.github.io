Pages

The site initializer creates these pages. Addresses are relative to the site, for example /web/forums.

PageAddressWhat It ShowsWho Can See It
Forums/forumsHome page: statistics, search, promoted discussions, categoriesEveryone
Forums Messages/forums-messagesThe discussions list, filtered by category or tagEveryone
New Discussion/new-discussionThe form to start a topicSigned-in members
Search/searchSearch results with facetsEveryone
Forums Moderation/forums-moderationThe moderation queueForum Moderators
Forum Categories Admin/forum-categories-adminCategory managementForum Category Admins
Liferay Learn, Help CenterLinks to Liferay's documentation and help centerEveryone

Each topic has its own page at /c_c2m0thread/<topic-title>, built from the Forum Thread display page template.

Pages open to everyone show topics only to signed-in members, unless an administrator lets guests read the forum.
