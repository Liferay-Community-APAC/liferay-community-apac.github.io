About the course

Over two days you build Clarity Vision Solutions' public website on Liferay DXP 2026.Q3: users and permissions, sites, pages and master pages, fragments, styling, CMS content, collections, commerce, headless APIs, workflow and publishing, search, Objects and personalization. You build it with an AI coding agent: each exercise gives you a prompt for the agent, then you check the result yourself in Liferay.

Bring a laptop you can install software on, and an AI coding agent you already have access to. The course doesn't provide an AI subscription. The course repository and workbook are shared on the first morning.

1

Prepare your computer

Install and check each item below. Run the commands in a terminal: the Terminal app on a Mac or Linux, or PowerShell on Windows.

Based on Liferay's classroom training prerequisites.

  • Any recent version. You don't need a GitHub account.

    How to install

    Windows

    Install Git for Windows from git-scm.com, or run the command below. During setup, choose to use Git from the command line and also from third-party software.

    winget install --id Git.Git -e

    macOS

    Run the command below and click Install when macOS asks. With Homebrew, you can run brew install git instead.

    xcode-select --install

    Linux

    On Ubuntu or Debian:

    sudo apt install git

    Check it

    git version

    You should see something like:

    git version 2.44.0

  • A JDK, not just a JRE, reporting a 21.x version.

    How to install

    Windows

    Install Microsoft Build of OpenJDK 21:

    winget install Microsoft.OpenJDK.21

    macOS

    With Homebrew:

    brew install --cask microsoft-openjdk@21

    Linux

    On Ubuntu or Debian:

    sudo apt install openjdk-21-jdk

    If java -version shows another version, set the JAVA_HOME environment variable to your JDK 21 folder and put its bin folder first in your PATH, then open a new terminal.

    Check it

    java -version
javac -version

    You should see something like:

    openjdk version "21.0.5" 2024-10-15 LTS
javac 21.0.5

  • Version 7.0 or later. Your AI agent uses it to build and deploy the client extensions you create. Install the JDK first.

    How to install

    macOS and Linux

    Run the command below. When it says Blade installed successfully, open a new terminal. If blade isn't found, add the folder the installer shows to your PATH.

    curl -L https://raw.githubusercontent.com/liferay/liferay-blade-cli/master/cli/installers/local | sh

    Windows

    Download and run the Liferay Project SDK installer: it detects your Java and adds blade to your PATH.

    If your version is older than 7.0, update it:

    blade update

    Check it

    blade version

    You should see something like:

    blade version 7.0.3

  • Liferay DXP, its search engine and the PostgreSQL database run on your computer in Docker, next to your editor and browser. You need 16 GB of memory installed, and Docker gets 8 GB of it (step 2). Close other heavy applications during the course.

  • A company laptop may block installs, Docker or local servers. Check with your IT team before the course, and ask them to allow ports 8080 and 5432 on localhost.

  • Working through this Liferay Learn course first lets the workshop move faster and go deeper.

2

Install Docker

Docker is required. The course runs Liferay DXP and its PostgreSQL database as containers, so the setup is the same on every system. On macOS and Windows, choose one of two options:

  • Option A, free: Colima on macOS, Rancher Desktop on Windows. Free and open source, for any company size.
  • Option B, Docker Desktop: if you already have it, or your company licenses it. Docker Desktop is free only for personal use, education and small businesses (fewer than 250 employees and less than $10 million in revenue).

On Linux, use Docker Engine: it's free. Install only one option. If you have both, quit the one you don't use before the course.

  • Option A or B on macOS and Windows, Docker Engine on Linux. Start it before you check it.

    How to install

    macOS, option A (free): Colima

    Needs macOS 13 or later and Homebrew. Install Colima, the Docker command line and Docker Compose, let Docker find Compose, then start Colima with the 8 GB of memory and 4 CPUs the course needs:

    brew install colima docker docker-compose
mkdir -p ~/.docker/cli-plugins
ln -sfn "$(brew --prefix)/opt/docker-compose/bin/docker-compose" ~/.docker/cli-plugins/docker-compose
colima start --cpu 4 --memory 8 --vm-type vz --mount-type virtiofs

    Colima doesn't start on its own after you restart your Mac: run colima start again (it remembers the settings). Colima shares your home folder with the containers, so keep the course folder inside it, as the workbook does.

    macOS, option B: Docker Desktop

    Install Docker Desktop for Mac for your chip (Apple silicon or Intel), or use Homebrew. Then open Docker from Applications. It includes Docker Compose.

    brew install --cask docker

    Windows, option A (free): Rancher Desktop

    Install Rancher Desktop, or run the command below, then start it. On first start, choose these two settings (later, in Preferences):

    • Container engine: dockerd (moby), so the docker and docker compose commands work.
    • Kubernetes: off. It's on by default and uses memory Liferay needs.
    winget install --id SUSE.RancherDesktop -e

    Rancher Desktop runs its containers in WSL 2. If Windows asks to install or update WSL, accept and restart.

    Windows, option B: Docker Desktop

    Install Docker Desktop for Windows, or run the command below. Restart when asked, then start Docker Desktop. It includes Docker Compose and runs its containers in WSL 2.

    winget install --id Docker.DockerDesktop -e

    Linux: Docker Engine (free)

    Install Docker Engine and the Compose plugin for your distribution from Docker's own package repository (packages docker-ce and docker-compose-plugin). Then let your user run Docker without sudo, and sign out and back in:

    sudo usermod -aG docker $USER

    Check it

    docker compose version
docker run --rm hello-world

    You should see something like:

    Docker Compose version v2.29.1
...
Hello from Docker!
This message shows that your installation appears to be working correctly.

  • Liferay and its search engine need about 6 GB, and PostgreSQL needs some too. With less, Liferay restarts in a loop or stops with exit code 137.

    How to set it

    macOS, option A (Colima)

    The colima start command above already sets 8 GB. To change it later: colima stop, then colima start --memory 8.

    macOS, option B (Docker Desktop)

    Open Docker Desktop → Settings (the gear icon) → Resources → Advanced, set Memory to 8 GB or more, then click Apply & restart.

    Windows, option A or B (Rancher Desktop or Docker Desktop)

    Both run their containers in WSL 2, which gives Docker half of your computer's memory by default: 8 GB on a 16 GB laptop, so there's usually nothing to set. Only if the check below shows less than 7.5 GB, write the limit to .wslconfig in your user folder in PowerShell, restart WSL, then quit and start Rancher Desktop or Docker Desktop again. If you already have a .wslconfig, open it instead and set memory=8GB under [wsl2].

    Set-Content -Path "$env:USERPROFILE\.wslconfig" -Value "[wsl2]`nmemory=8GB"
wsl --shutdown

    Linux (Docker Engine)

    Docker Engine uses your computer's memory directly: nothing to set. Also check that id -u prints 1000: Liferay's container writes its log files for that user ID only, and your agent needs to read them. If it prints another number, also download the Liferay DXP bundle in step 3, so you can run Liferay without a container.

    Check it

    docker info --format "{{.MemTotal}}"

    You should see a number of bytes of about 8 GB or more, something like:

    8307101696

Download ahead of time

These downloads are a few GB. Do them at home or the office, so the course doesn't depend on the venue's Wi-Fi. Start Docker first.

  • Liferay DXP as a Docker image, for both Intel and Apple silicon. It's the largest download: about 2 GB, and about 5 GB on disk.

    Download and check it

    docker pull liferay/dxp:2026.q3.10
docker image ls liferay/dxp

    You should see a line for liferay/dxp with the tag 2026.q3.10. The columns differ between Docker versions.

    Only on Linux if id -u isn't 1000, or if your instructor asks: the Liferay DXP bundle

    The course can run Liferay as a Tomcat bundle instead of a container. Save the bundle (about 1.3 GB) in Liferay's download cache:

    mkdir -p ~/.liferay/bundles
curl -L -o ~/.liferay/bundles/liferay-dxp-tomcat-2026.q3.10-1793707249.7z https://releases-cdn.liferay.com/dxp/2026.q3.10/liferay-dxp-tomcat-2026.q3.10-1793707249.7z

  • The database Liferay runs on, in its own container.

    Download and check it

    docker pull postgres:16
docker image ls postgres

    You should see something like:

    REPOSITORY   TAG   IMAGE ID       CREATED       SIZE
postgres     16    3f8b2c1d9a7e   2 weeks ago   453MB

  • Liferay DXP needs an activation key file (.xml). Get one of these two before the course, and save it somewhere you can find it on the first morning. It's yours alone: don't share it or commit it to a repository.

    The free key's one limitation: the Liferay DXP Free Tier doesn't include Liferay Enterprise Search, so it has no Search Blueprints. Two exercises of Level 11 use blueprints, and the workbook gives each a free-key path that reaches the same result another way; one optional bonus exercise is skipped. Everything else in the course works the same on both keys. A developer key includes Search Blueprints.

    How to get it

    Free key (anyone)

    Sign in to one.liferay.com (create a free account if you don't have one), open the Liferay DXP Free Tier page and click Get Activation Key. You get a file named Liferay Free Activation Key.xml. It's valid for one year and works on localhost, which is where you run Liferay in the course.

    Developer key (if you have one)

    If your company is a Liferay customer or partner and has issued you a DXP developer key on one.liferay.com, you can use it instead. Make sure it covers Liferay DXP 2026.Q3 and hasn't expired.

Install your tools

You'll work in a Liferay Workspace in VS Code, with an AI coding agent at your side. Bring the agent you already have access to: it must have an agent mode that can run terminal commands and connect to an MCP server. One is enough, and ticking it completes this choice.

  • Or another editor your agent works in. The workbook's instructions use VS Code.

  • Choose one AI coding agent

  • Sign in with a Claude plan or account that includes Claude Code.

  • Sign in with your ChatGPT account. Codex comes with paid ChatGPT plans.

  • Sign in to VS Code with the GitHub account that has your Copilot access, and use the Chat view in Agent mode.

  • Any agent that reads Agent Skills from an .agents/ folder, runs terminal commands in your workspace and connects to an HTTP MCP server.

Optional, for the bonus exercises: Node.js 20 or later

Each level's last bonus exercise has your agent write a Playwright test of the level. Playwright runs on Node.js, and uses your Google Chrome if it's installed. The bonus Level 14, Liferay AI Hub, also needs Node.js: you build an AI chatbot with AI Hub's setup on a course mock of AI Hub that runs on your laptop, and your AI agent's command line writes the chatbot's answers. You don't need any of these for the course itself.

Windows

winget install OpenJS.NodeJS.LTS

macOS

With Homebrew:

brew install node

Linux

Install the LTS version from nodejs.org or your distribution's packages.

Check it

node --version

You should see v20 or later.

5

Check everything with your AI agent

Let the AI agent you installed in step 4 check your setup for you. It runs the checks in a terminal and tells you what passes and what to fix. It's also a good first test that your agent works.

  1. In VS Code, open any folder (File → Open Folder), for example your home folder or a new empty one.
  2. Open your AI agent's chat:
    • Claude Code: click the Claude icon, or run Claude Code: Open from the Command Palette.
    • OpenAI Codex: click the Codex icon in the sidebar.
    • GitHub Copilot: open the Chat view and switch the mode to Agent, so Copilot can run commands.
  3. Copy the prompt below, paste it into the chat and send it. When the agent asks to run a command, allow it: the checks only read information.
Prompt
Check that my computer is ready for the Building Enterprise Websites with Liferay and AI course. First tell me my operating system and shell. Then run each check in the terminal, one at a time. Don't install, update or change anything.

1. Git: run `git version`. PASS if Git is installed.
2. Java: run `java -version` and `javac -version`. PASS if both report version 21.x (a JDK, not just a JRE).
3. Blade: run `blade version`. PASS if it's 7.0 or later.
4. Docker: run `docker compose version` and `docker info --format "{{.ServerVersion}}"`. PASS if Compose is installed and the Docker engine answers (so it's running).
5. Docker memory: run `docker info --format "{{.MemTotal}}"`. PASS if it's at least 7.5 GB; FAIL otherwise, and tell me how to give Docker 8 GB on my operating system.
6. Images: run `docker image ls liferay/dxp:2026.q3.10` and `docker image ls postgres:16`. PASS if both images are listed.
7. Memory: report the total and the currently available RAM. PASS if at least 16 GB is installed; WARN if less than 8 GB is available now.
8. Disk: check the free space on the drive Docker stores its data on. PASS if at least 20 GB is free.
9. Ports: check whether anything is already listening on ports 8080 and 5432. PASS if both are free; otherwise WARN and tell me which program uses them.
10. Linux only: run `id -u`. PASS if it prints 1000; otherwise WARN: Liferay's container writes its logs for user ID 1000, so I should download the Liferay DXP bundle from step 3 of the prerequisites page.
11. Which Docker I use: run `docker context show` and tell me whether it's Colima, Rancher Desktop, Docker Desktop or Docker Engine. WARN if more than one of them is installed and running at the same time.

Then show the results as a table with the columns Check, Result (PASS, WARN or FAIL) and Details. For anything that isn't PASS, tell me how to fix it on my operating system.

Finally, list what I need to confirm myself, because you can't check it: that I have my Liferay DXP activation key file (the free key or a developer key), and that I can install software and run Docker on this computer during the course.

  • Run the check, fix anything marked FAIL or WARN, and run it again until everything passes. Then confirm the items it lists.

You're all set. See you at the course.
