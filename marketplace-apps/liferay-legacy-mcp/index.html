Liferay Legacy MCP

An MCP server for Liferay DXP 7.4 U1–U92 and 2024.Q1 to 2025.Q4

Connect AI assistants such as Claude Code and the Claude desktop app to Liferay DXP releases with no MCP of their own. They find, read and change content in plain language, with Liferay's permissions and a preview you confirm before anything changes. A community app for experimental use, which requires a Liferay DXP Enterprise Subscription.

Version 1.1.0 · Works with Liferay DXP 7.4 U1–U92 and 2024.Q1 to 2025.Q4

Read the guide → Download

Features

  • For releases with no MCP. Liferay DXP 7.4 U1–U92 and 2024.Q1 to 2025.Q4, without changing Liferay.
  • Runs outside Liferay. A separate container that uses Liferay's public Headless and JSON web service APIs. Nothing is installed into Liferay's code, so a Liferay update doesn't need a new server version unless an API it uses changes.
  • Only configuration in Liferay. The OAuth 2 client extension creates an OAuth application and adds no code to Liferay, so it isn't tied to a Liferay version.
  • Content tools. Search, read, create and update web content, documents, blogs, categories and tags, navigation menus and translations, and run review workflows.
  • Every API. Generic tools reach all of Liferay's Headless REST APIs and its JSON web services.
  • Safe writes. Writes are off by default. When on, every change is previewed and runs only once it's confirmed, and every attempt is audited.
  • Least privilege. One service user, through an OAuth 2 application whose scopes limit what it can reach. Liferay enforces both.
  • Claude Code and desktop. Add it with one claude mcp add command, or to the Claude desktop app's chats and Code tab.
