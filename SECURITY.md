# Reporting a security issue

Please don't report security vulnerabilities in public issues.

Report them privately instead: on the [website repository](https://github.com/Liferay-Community-APAC/liferay-community-apac.github.io), go to **Security → Report a vulnerability**
([direct link](https://github.com/Liferay-Community-APAC/liferay-community-apac.github.io/security/advisories/new)). Only the maintainers can see the report.

Include what's affected (the Marketplace App, tutorial or tool, and its version), how to reproduce it, and its impact.
We'll acknowledge it as soon as we can and keep you updated.

Vulnerabilities in Liferay DXP itself go to Liferay: see <https://liferay.dev/portal/security>.
