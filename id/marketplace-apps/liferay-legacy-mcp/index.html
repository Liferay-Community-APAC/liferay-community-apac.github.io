Liferay Legacy MCP

Server MCP untuk Liferay DXP 7.4 U1–U92 dan 2024.Q1 hingga 2025.Q4

Hubungkan asisten AI seperti Claude Code dan aplikasi desktop Claude ke rilis Liferay DXP yang belum memiliki MCP sendiri. Asisten dapat mencari, membaca, dan mengubah konten dengan bahasa sehari-hari, sesuai izin Liferay, dengan pratinjau yang Anda konfirmasi sebelum ada perubahan. Aplikasi komunitas untuk penggunaan eksperimental.

Versi 1.1.0 · Untuk Liferay DXP 7.4 U1–U92 and 2024.Q1 to 2025.Q4

Baca panduan (bahasa Inggris) → Unduh

Fitur

  • Untuk rilis tanpa MCP. Liferay DXP 7.4 U1–U92 dan 2024.Q1 hingga 2025.Q4, tanpa mengubah Liferay.
  • Berjalan di luar Liferay. Kontainer terpisah yang menggunakan Headless API dan layanan web JSON publik Liferay. Tidak ada yang dipasang ke dalam kode Liferay, sehingga pembaruan Liferay tidak memerlukan versi server baru kecuali API yang digunakannya berubah.
  • Hanya konfigurasi di Liferay. Ekstensi klien OAuth 2 membuat aplikasi OAuth dan tidak menambahkan kode apa pun ke Liferay, sehingga tidak terikat pada versi Liferay tertentu.
  • Alat konten. Cari, baca, buat, dan perbarui konten web, dokumen, blog, kategori dan tag, menu navigasi, serta terjemahan, dan jalankan alur kerja peninjauan.
  • Semua API. Alat generik menjangkau semua Headless REST API Liferay dan layanan web JSON-nya.
  • Penulisan yang aman. Penulisan nonaktif secara bawaan. Jika diaktifkan, setiap perubahan ditampilkan sebagai pratinjau dan hanya dijalankan setelah dikonfirmasi, dan setiap percobaan dicatat dalam log audit.
  • Hak akses minimum. Satu pengguna layanan, melalui aplikasi OAuth 2 yang cakupannya membatasi apa yang dapat dijangkau. Liferay menegakkan keduanya.
  • Claude Code dan desktop. Tambahkan dengan satu perintah claude mcp add, atau ke obrolan dan tab Code di aplikasi desktop Claude.
